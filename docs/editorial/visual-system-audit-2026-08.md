# Visual System Audit - 2026-08

## Scope

Vol. 001/002の正式カバー、公開済み記事hero 11件、sidecar metadata、専属モデル台帳、正式計画、役割カード、CIゲート、回復規則を実画像と記録の両方から点検した。

## Findings

| Observation | Result |
| --- | --- |
| 公開済み記事hero | 11件 |
| 実写調に見えるhero | 11件 |
| イラスト／コラージュ | 0件 |
| `modelId`を持つhero | 0件 |
| 専属モデル台帳 | 6名、reference sheetあり |

同カテゴリ間では、とくに次の反復が確認された。

- STYLE: 白または淡青のシャツ、窓辺、静かな室内
- LIFE: 鞄、ベンチまたは台、物を入れる匿名の手元
- WEEKEND: 日陰の街路を歩く後ろ姿
- CULTURE: 畳んだシャツ、本、音響機器、窓
- SHOPPING: 革靴、手入れの手元、低い位置の物撮り

## Root Causes

1. ポリシーはイラスト、コラージュ、専属モデルを許可していたが、Vol.全体で実際に使う約束がなかった。
2. `compositionFamily` が自由記述だったため、文字列だけを変えて似た視覚文法を通せた。
3. 直近記事との比較はあったが、前Vol.の同カテゴリ記事との比較がなかった。
4. `visualMode` に媒体の `photorealistic` と主題の `still-life` が混在し、frontmatterとsidecarの不一致も検査されなかった。
5. 正式計画がカテゴリごとの具体構図を先に固定し、アートディレクターが記事と誌面全体から表現を選ぶ余地を狭めていた。
6. 専属モデルは任意利用に留まり、PEOPLE記事でも匿名の後ろ姿を選べた。
7. 回復規則は品質ゲートの保持を定めていたが、媒体やモデル選定を高速化のために単純化しない条件が明記されていなかった。

## Resolution

Vol. 003以降は次をCIで検査する。

- 正式計画で非実写調1カテゴリと専属モデル1カテゴリを別々に予約する。
- 編集長は休ませる直近パターンを3件記録するが、具体構図とモデルはビジュアル編集へ委ねる。
- sidecarは管理語彙で媒体、構図、場所、視点、人物の扱いを別々に記録する。
- 直前の同カテゴリheroを明示し、比較可能な視覚軸を3件以上変える。
- 専属モデル枠は有効な `modelId` を必須にする。
- frontmatterとsidecarの媒体を一致させる。
- 正式カバーも前Vol.から3軸以上変える。
- Production recoveryは合格済みのアート方針とartifactを保持する。

既刊の画像は公開当時の記録として保持し、遡及的なmetadataの取り繕いはしない。新しいゲートはVol. 003から適用する。
